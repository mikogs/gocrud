# Demo

This demo is a complete program that you can run. It defines a model, creates a table for it, and creates, reads, updates, lists and deletes records. It uses an in-memory SQLite database, so it does not need a database server.

Create a new module and get the packages:

```sh
go mod init demo
go get github.com/mikogs/gocrud modernc.org/sqlite
```

Then put the code from the sections below, in order, in `main.go`, and run it with `go run .`.

## 1. Define the model

```go
package main

import (
	"context"
	"database/sql"
	"errors"
	"fmt"
	"log"
	"strconv"
	"time"

	"github.com/mikogs/gocrud"
	sqlfilters "github.com/mikogs/gocrud/pkg/filters"
	_ "modernc.org/sqlite"
)

// User represents the data model to be stored in the database.
type User struct {
	ID         uint64    `json:"id"`
	Username   string    `json:"username" validate:"required,min=3,max=30" crud_regexp:"^[a-z0-9_-]+$" crud:"uniq"`
	Email      string    `json:"email" validate:"required,email"`
	FirstName  string    `json:"first_name" validate:"required,min=2,max=50"`
	LastName   string    `json:"last_name" validate:"required,min=2,max=50"`
	Department string    `json:"department" validate:"max=100" crud:"idx"`
	IsActive   bool      `json:"is_active"`
	LastLogin  time.Time `json:"last_login"` // zero when the user has never logged in
	CreatedAt  time.Time `json:"created_at"`
	CreatedBy  uint64    `json:"created_by"`
	ModifiedAt time.Time `json:"modified_at"`
	ModifiedBy uint64    `json:"modified_by"`
}
```

A few important conventions:

* Every struct must have an `ID` field of type `uint64` as its first field. It is the primary key, generated by the database.
* `CreatedAt`, `CreatedBy`, `ModifiedAt` and `ModifiedBy` are filled in by `Save`, see [Creation and modification fields](struct.md#4-creation-and-modification-fields).
* Validation rules are written in the `validate` tag, and regular expressions in `crud_regexp`. gocrud uses the [go-playground/validator](https://github.com/go-playground/validator) library, see its documentation for all the rules.
* The `crud` tag sets database options: `uniq` adds a `UNIQUE` constraint, and `idx` creates an index. See [Struct](struct.md) for all the options and supported field types.

## 2. Create the table

`main` opens the database, creates the CRUD object and the table, and then runs the operations below.

```go
func main() {
	ctx := context.Background()

	db, err := sql.Open("sqlite", ":memory:")
	if err != nil {
		log.Fatal(err)
	}
	defer db.Close()
	// an in-memory database exists only within one connection
	db.SetMaxOpenConns(1)

	crud := gocrud.New(db, gocrud.Options{Dialect: gocrud.DialectSQLite})

	if err := crud.CreateTable(ctx, &User{}); err != nil {
		log.Fatal(err)
	}

	// the user who makes the changes, e.g. the one logged in to the application
	adminID := uint64(1)

	createUsers(ctx, crud, adminID)
	user := loadUser(ctx, crud, 2)
	updateUser(ctx, crud, user, adminID)
	listUsers(ctx, crud)
	deleteUser(ctx, crud, user)
	saveInvalidUser(ctx, crud, adminID)
}
```

`CreateTable` creates the table and its indexes if they do not exist yet. Table and column names are generated from the struct and field names: `User` is stored in the `user` table, and `FirstName` in the `first_name` column.

To use PostgreSQL instead, import `github.com/lib/pq`, open the database with `sql.Open("postgres", "host=localhost user=... dbname=... sslmode=disable")`, and set `Dialect` to `gocrud.DialectPostgres`. `SetMaxOpenConns(1)` is needed only for the in-memory SQLite database.

## 3. Create

`Save` inserts an object when its `ID` is `0`, and sets the `ID` generated by the database.

```go
func createUsers(ctx context.Context, crud *gocrud.CRUD, adminID uint64) {
	users := []*User{
		{Username: "alice", Email: "alice@example.com", FirstName: "Alice", LastName: "Anderson", Department: "Engineering", IsActive: true},
		{Username: "bob", Email: "bob@example.com", FirstName: "Bob", LastName: "Brown", Department: "Engineering", IsActive: true},
		{Username: "carol", Email: "carol@example.com", FirstName: "Carol", LastName: "Clark", Department: "Engineering", IsActive: false},
		{Username: "dave", Email: "dave@example.com", FirstName: "Dave", LastName: "Davis", Department: "Sales", IsActive: true},
	}

	for _, user := range users {
		if err := crud.Save(ctx, user, gocrud.SaveOptions{ModifiedBy: adminID}); err != nil {
			log.Fatalf("saving %s: %v", user.Username, err)
		}
		fmt.Printf("created %s with ID %d\n", user.Username, user.ID)
	}
}
```

## 4. Read

`Load` reads the object with the given ID. When there is no such object, it returns no error and leaves `ID` at `0`.

```go
func loadUser(ctx context.Context, crud *gocrud.CRUD, id uint64) *User {
	user := &User{}
	if err := crud.Load(ctx, user, strconv.FormatUint(id, 10), gocrud.LoadOptions{}).Error; err != nil {
		log.Fatalf("loading user %d: %v", id, err)
	}
	if user.ID == 0 {
		log.Fatalf("user %d not found", id)
	}

	fmt.Printf("loaded %s, created at %s\n", user.Username, user.CreatedAt.Format(time.RFC3339))
	return user
}
```

## 5. Update

`Save` on an object with an `ID` updates it. `ModifiedAt` and `ModifiedBy` are set again, while `CreatedAt` and `CreatedBy` keep their values.

```go
func updateUser(ctx context.Context, crud *gocrud.CRUD, user *User, adminID uint64) {
	user.LastName = "Baker"
	user.LastLogin = time.Now()

	if err := crud.Save(ctx, user, gocrud.SaveOptions{ModifiedBy: adminID}); err != nil {
		log.Fatalf("updating %s: %v", user.Username, err)
	}
	fmt.Printf("updated %s, now %s %s\n", user.Username, user.FirstName, user.LastName)
}
```

## 6. List

`Get` returns the objects that match the filters, in the given order. `Order` is a list of field names and directions, and the filters map field names to an operator and a value. See [Operations](crud/ops.md#get) for all the options, including raw SQL conditions and pagination.

```go
func listUsers(ctx context.Context, crud *gocrud.CRUD) {
	objs, _, err := crud.Get(ctx, func() interface{} { return &User{} }, gocrud.GetOptions{
		Order: []string{"Username", "asc"},
		Limit: 10,
		Filters: &sqlfilters.Filters{
			"Department": {Op: sqlfilters.OpEqual, Val: "Engineering"},
			"IsActive":   {Op: sqlfilters.OpEqual, Val: true},
		},
	})
	if err != nil {
		log.Fatalf("listing users: %v", err)
	}

	fmt.Printf("active users in Engineering:\n")
	for _, obj := range objs {
		user := obj.(*User)
		lastLogin := "never"
		if !user.LastLogin.IsZero() {
			lastLogin = user.LastLogin.Format(time.RFC3339)
		}
		fmt.Printf("  %s %s (%s), last login: %s\n", user.FirstName, user.LastName, user.Email, lastLogin)
	}
}
```

## 7. Delete

`Delete` removes the object from the database, and sets all its fields to their zero values.

```go
func deleteUser(ctx context.Context, crud *gocrud.CRUD, user *User) {
	id := user.ID
	if err := crud.Delete(ctx, user, gocrud.DeleteOptions{}); err != nil {
		log.Fatalf("deleting user %d: %v", id, err)
	}
	fmt.Printf("deleted user %d\n", id)
}
```

## 8. Validation errors

`Save` validates the object first. When it is invalid, nothing is saved and the error is a `*gocrud.ValidationError`, with the name of the failed rule for each field.

```go
func saveInvalidUser(ctx context.Context, crud *gocrud.CRUD, adminID uint64) {
	user := &User{Username: "Eve!", Email: "not-an-email", FirstName: "Eve", LastName: "E"}

	err := crud.Save(ctx, user, gocrud.SaveOptions{ModifiedBy: adminID})

	var validationErr *gocrud.ValidationError
	if errors.As(err, &validationErr) {
		fmt.Printf("invalid user: %v\n", validationErr.Violations)
	}
}
```
